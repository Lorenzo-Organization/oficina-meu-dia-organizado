# Tarefas dos 70 minutos

Siga na ordem. Marque a caixinha quando terminar.
Os minutos ao lado são só uma referência para não passar do tempo.

## Começo (10 min)

- [ ] Ler o `README.md` (5 min). Uma pessoa lê em voz alta a parte "A solução".
- [ ] Conferir o `CLAUDE.md` com o grupo (5 min). Preencher a parte "O que nunca mexer" com o que só a empresa sabe: horários fixos, quando o sócio não pode ser interrompido, o que é prioridade.

## Ver funcionando (10 min)

- [ ] Abrir o `index.html` no navegador. Se der aviso vermelho, rodar `npx serve .` e abrir o endereço.
- [ ] Testar: digitar "ligar pro posto às 14h" e apertar Guardar. Ver que virou compromisso.
- [ ] Testar: digitar "cotar pneu" com "pode esperar" e apertar Guardar. Ver que foi para a lista certa.
- [ ] Testar: marcar um item como feito e desfazer.
- [ ] Apertar "Copiar agenda para o sócio" e colar em algum lugar para ver o texto.

## Primeiro passo da proposta principal (30 min)

- [ ] Abrir a pasta no Claude Code.
- [ ] Montar a planilha de verdade, mesmo rabiscada: as tarefas típicas de uma semana e os compromissos fixos com dia e hora. Salvar como CSV em `dados/`.
- [ ] Copiar o Pedido 1 do README, ajustar o nome do arquivo e mandar para a IA.
- [ ] Abrir a tela de novo e conferir se os dados de verdade aparecem no dia de hoje.
- [ ] Anotar o que ficou estranho ou errado. Pedir para a IA arrumar, uma coisa por vez.

## Se sobrar tempo (10 min)

- [ ] Pedir para a IA uma melhoria pequena. Ideias: mostrar o dia da semana maior, ou colocar os compromissos do sócio numa cor diferente.
- [ ] Se estiver fácil, copiar o Pedido 3 do README, do resumo do fim do dia.

## Fechar (10 min)

- [ ] Salvar uma versão: copiar a pasta inteira com o nome `meu-dia-organizado-sessao-1`, ou pedir para a IA guardar uma versão com git.
- [ ] Anotar no `DIARIO.md`: o que fizemos, o que decidimos, o que falta, onde paramos.
